Multi-instance

One client per account, side by side.

min
RAM limit per instance
Caps the RAM each client can hold.
Anything above the cap is paged to disk, so the game keeps running, but too low a cap makes it stutter. 512 MB is the lowest cap; leave it empty for no limit. Applies to running clients right away, and Edit account can override it per account.
MB
CPU
Lower priority when several run
Leaves more CPU for the rest of your PC.
Once more than one account is running, every client drops to Below Normal priority so Windows doesn't split the CPU evenly across idle clients. Goes back to Normal when one is left.
Windows
Headless clients
Runs clients with no window or taskbar button. They draw nothing.
The window is minimized and then hidden, so the client has nothing to draw. The game keeps running as normal: physics, scripts and the connection carry on, and anti-AFK and tracking still work. Applies to accounts whose window is set to Default in Edit account, Performance, including ones already running. Right-click an account to show its window.

shield
Antivirus warnings
Some scanners flag RobloxNative.exe. Running two Roblox clients at once requires closing Roblox's single-instance lock, which looks like a cheat tool to heuristic scanners. It's a false positive, the helper is one readable C# file in the repo, and the app isn't code-signed so nothing vouches for it automatically.
